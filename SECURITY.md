# Security

Report a vulnerability privately, by email to dev@proofpane.com, and not in a public issue, pull request or
discussion, where anyone could read it while the vulnerability can still be used.

A report holds:

- what it concerns: Proofpane Community (`open_edition/`) or which of the open packages (`oss/`), the file or route,
  and the commit you read or ran;
- how to show it: the steps from a fresh start, what you expected and what happened instead;
- what it reaches: what someone using it gains, and what they need first (an account, a linked session, a device, a
  place on the network);
- how to reach you, and whether you have told anyone else.

This covers the code in this repository at the newest commit on `main`: Proofpane Community and the open packages.

Test on an installation of your own. Do not test against the hosted Proofpane Community, or against a deployment that
someone else runs.

No response time and no reward are offered: neither is decided.
