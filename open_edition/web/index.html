What the ADE is

The control room for the coding sessions you run yourself, in the cloud and on your machine, in Anthropic's or OpenAI's own programs. It reads the branch where they pass work to each other and the repositories they change, and shows what each session did and what it is waiting for. Each commit on a verified branch is checked by Verify and the manifest is signed with ML-DSA-65 and Ed25519 together; a merge, the first commit, a commit with no change and one whose diff is over 1 MB are recorded as skipped, with the reason, and a commit that cannot be read or checked as an error. Where this deployment turns on the hosted workspace, it also runs Anthropic's and OpenAI's own claude and codex programs, unmodified, in a workspace of your own: you sign in inside the terminal, in the program's own flow, and nothing here reads that sign-in.

The workspace's gate holds Claude Code through managed settings a session cannot change (read in Claude Code's text, not measured: on a seat whose organisation sends server-managed settings, those replace the image's, so an agent's own run and a chat there run without the gate, while a task's attempt keeps its own callbacks); Codex, Grok Build, Qwen Code and Gemini CLI through files the image installs as root, which a user's or a repository's settings cannot turn off, each in its own way (the manual says how); Kimi Code and MiniMax Code only through settings a session can change, so the gate does not count on them; OpenCode has no hooks. Measured on 2026-10-12 for Codex, Grok Build, Qwen Code and Gemini CLI, on a measurement image built on the release image's own base with a recorder standing in for the gate and each program driven headless: no repository's or session's file left the gate unrun while the call went ahead, with three residuals the manual names.
