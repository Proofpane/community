# AI Risk Assessment

Use this skill when assessing AI system risk, impact, autonomy, data
sensitivity, foreseeable harm, or approval pathway.

Prefer conservative risk tiering when facts are missing. Every high-risk
finding must include an accountable owner, evidence need, and review gate.
