# AI Governance Intake

Use this skill when a workflow needs to turn an unstructured AI idea, vendor
request, or model launch proposal into an auditable governance intake record.

Outputs should separate confirmed facts, assumptions, missing evidence, and the
owner who must resolve each open question.
